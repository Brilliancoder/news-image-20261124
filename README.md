Entry for the make.fun bounty **news-image-20261124**: the world's news of
Tuesday 24 November 2026 in one 1024x1024 image.

- `main.py` (Python 3.13, stdlib only, no network) writes `entry.png` to `/output`
  (or `$MAKEFUN_OUTPUT_DIR`). Same bytes every run.
- `build.py` renders `entry.png` at build time (Pillow + Noto fonts): `python3 build.py`.
